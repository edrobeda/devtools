## Teste antes de subir
1. `cd /home/devtools-bot/devtools && npm install` (só se necessário)
2. `docker compose build` — se der erro de build, corrija antes de seguir.
   Não suba nada quebrado.
3. Depois do build passar limpo: `docker compose up -d`
4. Confirme que o container `DK_DEVTOOLS` subiu (`docker ps --filter
   name=DK_DEVTOOLS`) e que `curl -s -o /dev/null -w '%{http_code}'
   https://devtools.eventifylab.com/` retorna 200.
5. `curl` 200 não garante que o JS rodou sem erro — sempre confira num
   headless browser (Puppeteer, instalado só numa pasta separada tipo
   `.scratch/`, NUNCA adicionado ao `package.json` principal do projeto)
   que não há `pageerror`/erro de console na home e nas páginas que você
   mexeu. Um erro de carga de módulo já derrubou o site inteiro (todas as
   rotas compartilham o mesmo bundle) por causa de um bug numa única
   página.
6. Se você removeu uma página, confirme que a rota antiga responde algo
   sensato (404 da própria SPA é aceitável — não precisa configurar
   redirect).
